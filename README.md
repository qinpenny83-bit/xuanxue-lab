# 🔮 玄学实验室

> 别急着算，先学会怎么看。
> 把玄学变成一场可以玩的推理游戏。

一个**完全本地化、零外部 API、零后端**的玄学学习操作系统。它不是算命网站，也不是内容展示页，而是一个围绕「学 → 玩 → 练 → 验 → 复盘 → 会」闭环构建的学习 Agent。

---

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173` 即可使用。

无需任何 API Key、`.env`、后端服务、数据库或第三方账号。所有知识与计算都在浏览器本地完成，用户数据保存在 `localStorage`。

其他命令：

```bash
npm run build     # 打包为静态产物到 dist/
npm run preview   # 本地预览打包产物
npm test          # 运行核心算法与业务逻辑测试
```

## 已实现的 Agent 能力

本地 Agent 不依赖任何 LLM，其「智能感」来自：用户状态 + 学习路径 + 规则引擎 + 知识库 + 案例引擎 + 错误识别 + 自适应任务。

- **掌握度建模**：0 未接触 / 1 看过 / 2 能解释 / 3 能识别 / 4 能应用 / 5 能分析 / 6 能发现错误；「真正掌握」至少达到 4 级。
- **错误识别**：识别并累计 E01–E10 共十类思维误区（如单变量下结论、相关当因果、过度解释等），自动调整后续学习路径。
- **推荐引擎**：前置知识未完成先补前置，否则按难度递进并优先薄弱维度，推荐具体的课程 / 案例 / 实验。
- **个性化反馈**：根据用户作答对错与错误类型，生成「做对了哪里 / 容易犯什么错 / 记住什么 / 下一步做什么」。
- **可回答三个 Agent 层问题**：用户现在学到哪了？最容易犯什么错？下一步该学什么、为什么？

## 内容概览

- 课程：8 节互动微课（首节《五行到底是什么？》）
- 案例：6 个多步盲测案例（首案《为什么她最近突然想换工作？》，含多维评分）
- 实验：5 个现实实验（首个《连续 7 天观察自己的状态》，含规则报告）
- 知识节点：13 个；词典词条：随知识库同步
- 起卦方式：时间起卦 / 数字起卦 / 硬币起卦，过程可复现、可解释

## 数据与备份

所有数据保存在 `localStorage`，键包含 `user_profile`、`learning_progress`、`mastery_scores`、`completed_lessons`、`case_history`、`error_patterns`、`experiment_records`、`daily_tasks`、`achievements`、`settings`。

在「我的成长」页可**导出 / 导入 JSON**、**清空数据**进行备份与迁移。

## 反迷信设计

- 明确区分「传统体系观点」与「现实中是否成立」，不把玄学包装成现代科学事实。
- 五行数量只是基础信息，不等于性格或命运的最终判断。
- 实验报告明确写明：实验结果不是为了证明玄学一定正确，而是帮助观察自己的判断是否经得起现实记录。
- 全站禁用「命中注定 / 一定会 / 百分百准确 / 科学证明 / 精准预测」等语言（除讨论这些说法为何有问题）。

---

## 精度说明

- 八字日柱采用公历 → 儒略日序数推算，月柱以天文二十四节气中十二「节」为界（立春换年）。节气使用低精度太阳视黄经算法，精度约为分钟级，用于学习与基础说明，非天文台级。
- 验证样本：1949-10-01 → 己丑年 癸酉月 甲子日 辛未时。
